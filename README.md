# Bingo Show Pro

Desenvolver um app para rodar sem internet (off line) em windows ou celular, com o intúito de fazer jogo do Bingo

As regras são as que são utilizadas pelo jogo do bingo. O app poderá ser replicado em um Telão (datashow) então deixar no formato mais adequado.

Ter opção de realizar novo jogo, limpar o jogo existente (reiniciar nova cartela).

Fazer o controle de como estão as cartelas vendidas, quantos estão com quantos números marcados, para que saibamos se alguém já está "pifado", ou quantos

números restam a marcar.

Em resumo, Desenvolver o jogo do bingo, com possibilidade de configurar quantos anúncios desejamos, com layout diferentes, podendo anexar

logo de empresas, colocar o nome do Bingo, ter central de configuração onde possam ser configurados todos os parâmetros de anúncios, propagandas, para

que possa ser mostrado por determinado tempo cada anúncio, ou carrocel, enfim, faça a melhor forma que julgar.

Lembrando criar o app sem necessidade de internet para utilisá-lo.
